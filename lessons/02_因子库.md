# 第 2 课 · 因子库：把"想法"变成每只股票每天的一个分数

## 1. 什么是因子

**因子 = 每个交易日，给股票池里每只股票打的一个分数。** 我们希望这个分数和股票【未来】的收益有关系。

| date | code | mom_5（过去 5 日收益） |
|---|---|---|
| 2024-03-01 | A | +12% |
| 2024-03-01 | B | -3% |
| 2024-03-01 | C | +1% |

每一个因子背后都是一个**关于市场的假设**。比如"过去 5 天涨得多的股票，未来几天会回调"（短期反转）。
第 3 课会检验这些假设在 A 股上到底成不成立；这一课只负责把分数算对。

和推荐系统对照：因子就是特征（feature），股票就是 item，每个交易日是一次请求。

## 2. 两种计算方向：时序 vs 截面

- **时序计算**（沿着一只股票的历史往回看）：过去 20 日收益、波动率、平均换手……这一课的大部分因子都是这种。
- **截面计算**（同一天在所有股票之间比较）：排名、标准化、行业中性化……第 3 课做。

时序计算必须**每只股票各算各的**，这就是 `.over("code")` 的作用。

## 3. 第一条铁律：不能用未来数据

> t 日的因子值，只能用 t 日收盘及以前的数据。

我们的约定是：t 日收盘后算出因子 → t+1 日交易 → 用 t+1 日之后的收益检验。只要因子里偷看了 t 日之后的任何数据，
回测就会好得离谱，而实盘完全复现不了。这是新手最常见、也是面试官最爱追问的错误。

Polars 里的规则很简单：
- `shift(n)` 中 n > 0 是看过去 ✅，n < 0 是看未来 ❌
- `rolling_mean / rolling_std / rolling_max ...` 默认只看当前行和之前的行 ✅

`tests/test_factors.py` 里有一个**篡改未来数据的测试**：把第 300 天以后的数据全改掉，如果第 300 天及以前的因子值变了，说明偷看了未来。
它会自动对注册表里的每一个因子跑一遍。

## 4. 第二条：收益类因子用复权价格

送转除权日原始 `close` 会出现假跳空（第 1 课讲过）。所以：
- 算"过去 N 日涨了多少"→ 用 `adj_close` 或 `ret`
- 价格水平本身有意义的（比如低价股）→ 才用原始 `close`

## 5. 第一批 12 个因子

| 类别 | 因子 | 背后的假设（A 股上常见的经验，第 3 课自己验证） |
|---|---|---|
| 反转/动量 | `mom_5`, `mom_20` | 短期涨多了会跌回来（反转） |
| | `mom_12_1` | 过去一年（跳过最近一个月）的趋势会延续（动量），A 股上通常较弱 |
| 波动 | `vol_20` | 低波动股票长期反而跑赢（低波异象） |
| | `max_ret_20` | 最近有过暴涨的"彩票股"被追捧过度，未来跑输 |
| 换手 | `turn_20` | 换手越高越被炒作，未来跑输 |
| | `abn_turn_5_120` | 近期换手相对自身历史突然放大，往往是情绪过热 |
| 流动性 | `amihud_20` | 不流动的股票要给更高收益作补偿 |
| 量价 | `pv_corr_20` | 价量同向/背离反映不同类型资金的行为 |
| 规模 | `log_size` | 小市值股票长期跑赢（A 股小市值效应很强，但波动也大） |
| 估值 | `ep`, `bp` | 便宜的股票长期跑赢（价值效应） |

## 6. 代码设计：因子 = 返回表达式的函数

```python
def mom(n: int, skip: int = 0) -> pl.Expr:
    return ...   # 只描述"对一只股票怎么算"，不实际计算
```
- 写因子时只考虑**一只股票**的时间序列；分组 `.over("code")` 由 `compute_factors` 统一加
- 表达式可以组合：`abn_turn` 直接调用 `turn_mean`
- 测试时在一张小表上 `df.select(表达式)` 就能验证，不需要真实数据

## 8. Sanity check 思考题
- `mom_12_1` 的缺失比例为什么比 `mom_5` 高？
- `ep` 的 1% 分位是负数，说明什么？
- `log_size` 的中位数换算回市值大约是多少亿？合理吗？
- `amihud_20` 的数值非常小（1e-10 量级），这会影响后面的研究吗？（提示：第 3 课用的是排名）
