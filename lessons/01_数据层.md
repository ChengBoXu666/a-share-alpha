# 第 1 课 · 数据层：为什么 80% 的回测是错的

## 1. 先建立概念（读完再写代码）

量化研究最大的敌人不是模型不够强，而是**回测在骗你**。数据层的坑有这些：

| 坑 | 后果 | 我们怎么处理 |
|---|---|---|
| **幸存者偏差**：只用现在还活着的股票 | 退市的垃圾股被删掉，回测虚高 | 下载时包含已退市股票 |
| **复权错误**：直接用不复权价格算收益 | 分红送转那天出现假的 -50% | 用 `close/preclose-1`（交易所 preclose 已除权） |
| **涨跌停**：涨停时你买不进，跌停时卖不出 | 回测买到了根本买不到的涨停股 | `limit_up / limit_down` 标记，回测时用 |
| **停牌** | 停牌股不能交易，价格是假的 | `is_suspended` |
| **ST / 次新股** | 流动性和风险特殊，实盘一般不碰 | `in_universe` 过滤 |
| **未来信息（look-ahead）** | 用了 t 日之后才知道的信息 | 贯穿整个项目，后面每一课都会讲 |

> 面试官最爱问："你的回测怎么保证没有未来函数？" 这一课就是答案的第一部分。

## 4. 第 2 步：你的作业 —— 实现 `src/ashare/clean.py`

**Polars 你需要会的几个东西**（不会就查 https://docs.pola.rs ）：
- `df.with_columns(新列=表达式)`
- `pl.when(条件).then(值).otherwise(值)`，可以链式写多个 `.when`
- `pl.col("code").str.starts_with("sh.688")`
- 分组内计算：`(1 + pl.col("ret")).cum_prod().over("code")`（要先 sort）
- 日期相减：`(pl.col("date") - pl.col("ipo_date")).dt.total_days()`
- `df.join(other, on="code", how="left")`

建议顺序：`add_board` → `add_status` → `add_returns` → `add_list_days` → `add_universe` → `add_limit_flags`（最难的放最后）。
