# A 股多因子选股研究框架（ashare-alpha）

> 目标：搭一条完整、无未来信息、带真实交易约束的研究流水线 数据 → 因子 → 因子检验 → 模型合成 → 组合构建 → 回测 → 报告

## 路线图

| 阶段 | 内容 | 产出 | 验收标准 | 状态 |
|----|----|----|----|----|
| 0 | 环境 + git | 能跑 `uv run pytest` | 环境装好 | ⬜ |
| 1 | 数据层 | `panel.parquet` | `tests/test_clean.py` 全过；sanity check 合理 | ⬜ |
| 2 | 因子库 | 30\~50 个量价/估值因子 | 每个因子有公式注释和单测，无未来信息 | ⬜ |
| 3 | 因子检验 | IC/RankIC/ICIR、分层、换手、衰减、相关性 | 每个因子一页报告 | ⬜ |
| 4 | 标签与模型 | 等权合成 vs LightGBM 滚动训练 | 样本外 RankIC 对比 | ⬜ |
| 5 | 组合与回测 | TopK、行业/市值中性、成本、涨跌停 | 净值曲线、超额、IR、回撤、换手 | ⬜ |
| 6 | 报告 | README 结论 + 局限性 | 能讲 15 分钟、扛住追问 | ⬜ |

## 快速开始

``` bash
uv sync                                         # 装环境（会自动下载 Python 3.12）
uv run python scripts/01_download.py --limit 20 # 试跑下载
uv run pytest -q                                # 跑测试
```

## 已知局限（诚实写出来是加分项）

- 行业分类用的是当前行业，不是历史时点行业
- 流通市值由 成交量/换手率 反推，是近似值
